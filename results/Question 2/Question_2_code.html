Question 2 Analysis

Association Between Track Preference and Programming Language

“Is there an association between programming language preference and a student’s career track orientation (Industry-only vs. Lab-inclined)?”

  • Variables: “type”, “language”, “response_id”, “domains”

  • Fixed Responses: Language choices are strictly “Python”, “R”, and “No preference”.

  • Data Prep: Recode type into two groups: “Industry Only” (ind) versus “Lab-Inclined” (combining lab and both).

  • Summaries & Plots: \(2 \times 3\) contingency table, Chi-Square test of independence (with Fisher’s Exact Test fallback if expected cell counts remain sparse), and a 100% proportion-filled bar chart.

  • Methodological Tradeoff: Grouping students who chose “both” with “lab” balances group totals so Chi-Square can be ran, but groups flexible students as having an affinity for academic lab work.

library(tidyverse)
library(here)

#Loading clean interest survey data with here (easier to access across different systems)
data_file <- here("data", "interest-clean.csv")
if (!file.exists(data_file)) {
data_file <- here("interest-clean.csv")
}

#Reading the dataset
interest <- read_csv(data_file, show_col_types = FALSE)

#Coding tracks into Industry Only vs. Lab-Inclined and setting factor levels
interest_comp <- interest %>%
  
  mutate(
    
    track_pref = case_when(
      type == "ind" ~ "Industry Only",
      type %in% c("lab", "both") ~ "Lab-Inclined"
    ),
    
    track_pref = factor(track_pref, levels = c("Industry Only", "Lab-Inclined")),
    
    coding_language = str_trim(language),
    coding_language = factor(coding_language, levels = c("Python", "R", "No preference"))
  )

#Checking values of two types to make sure we can actually run tests

Findings

  • Observed Shift: Industry-only respondents predominantly favored Python (53.1%) over R (15.6%), while Lab-inclined respondents showed a stronger leaning toward R (35.3%) compared to Python (29.4%). Both groups maintained similar rates of “No preference” (around 33%).

  • Statistical Significance: The Pearson Chi-Square test yielded \(X^2 = 3.36\) (\(p = 0.186\)), and Fisher’s Exact Test (accounting for the one cell with an expected count \(< 5\), yielded \(p = 0.181\). Because \(p > 0.05\), we fail to reject the null hypothesis of independence.

  • Conclusion: While the sample proportions suggest a visual leaning toward R within the Lab-inclined cohort (everybody not industry), there is insufficient evidence to conclude that programming language preference is significantly associated with career track interest in this cohort of students.

To answer this question, we classified students into Industry-Only (32 respondents) and Lab-Inclined (17 respondents who selected either lab or both tracks). As shown in Figure 1, language preferences show a visible split: Industry-Only students favored Python at 53.1% compared to just 15.6% for R, whereas Lab-Inclined respondents leaned toward R at 35.3% over Python at 29.4%, with “No preference” remaining nearly identical across both groups (~31% to 35%). However, formal hypothesis testing indicates this difference may be attributable to sample variation rather than a true underlying relationship. A Pearson’s Chi-Square test of independence resulted in \(X^2 = 3.359\) (\(p = 0.186\)), and a Fisher’s Exact Test—conducted because the expected count for Lab-Inclined students preferring R was under 5 (\(E = 3.82\))—yielded \(p = 0.181\). These results are shown in Figure 2. Because both \(p\)-values exceed the standard significance threshold of \(\alpha = 0.05\), we fail to reject the null hypothesis of independence and conclude there is insufficient statistical evidence of an association between career track interest and programming language preference.
